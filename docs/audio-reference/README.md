# Lily's voice reference

`lily_reference.wav` (62 s) joins 23 released Lily lines: the 19 lesson lines of release 2026-10-07 and 4 UI lines of release 2026-10-01. All are Kokoro-82M, Apache-2.0, in the app's voice mix `af_heart*0.7+af_bella*0.3`.

Use it as the sample for an Instant Voice Clone in ElevenLabs, so new sounds match Lily (`docs/tasks/AUDIO_TASK_short-vowels.md`). It is a reference only. It never ships in the app.
