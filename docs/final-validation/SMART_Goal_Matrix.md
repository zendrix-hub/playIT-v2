## 1. Purpose of This Matrix

In compliance with **Requirement D (`SMART_Goal_Matrix`)** of the *Requirements Before Adviser Presentation* (`IT411 | G1 - G8 | SEM1 | 2026-27`), this matrix maps **every measurable outcome** from:
1. **Part A — Originally Approved Proposal & Baseline SRS v2.0 SMART Goals** (`2526-sem2-it332-56_playIT_SRS.pdf` / Project Proposal Revised 4, May 2026), preserving the exact approved wording and measurable targets; and
2. **Part B — Post-MVP Refactored Operational Sub-Objectives (`HI`, `SI`, `O3`–`O6`)** (`SRS_v3.0_Refactored.md` & `docs/specs/hear-say-refactor.md`), showing how the deployed system operationalizes each outcome.

> **Methodological Alignment Note (Non-Questionnaire vs. Questionnaire Outcomes):**  
> Per the course directive (*"Remember that not all outcomes should be measured through questionnaires. For example, processing time, task completion rates, error rates, and system performance may require direct observation, system logs, or test results"*), this matrix explicitly assigns **System Telemetry Logs (`Instrument C`)**, **Hardware/ADB Benchmarks & Engineering Verification (`Instrument D`)**, **Blind Teacher-Rater Acoustic Audits (`Instrument A` & `Instrument B`)**, and **Silent-Observer Child Session Sheets (`Instrument B`)** to all behavioral, accuracy, and latency targets, reserving questionnaires (`Instrument E` TAM/SUS) strictly for stakeholder usability and pedagogical alignment constructs.
